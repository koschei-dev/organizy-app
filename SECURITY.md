# Security

Organizy moves files on your Mac, so security reports matter.

**Please don't open a public issue for a vulnerability.** Use the **Security** tab of this repository →
**Report a vulnerability**. Only the maintainer can see the report.

Useful details: Organizy version, macOS version, steps to reproduce, and what an attacker could do.

You'll get a reply within a week. Fixes ship as a new release, and the release notes credit you unless you'd rather not.
