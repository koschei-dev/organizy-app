how-it-works/

5 steps
1 choose

Pick a folder, or drag one onto the window or the Dock icon.

2 scan

Organizy reads each file's name, type, size and contents, and suggests a folder for it.

3 review

Check the list. Preview any file with Space, change a destination, or untick what should stay put.

4 move

Press Move Files. Only the files you left ticked move.

5 undo

Every batch is saved in History. One click puts everything back.

features/

7 items
review-first.list

Nothing moves until you confirm. You see every suggestion before a single file changes place.

reads-inside.pdf

Sorts by what files say, not just what they're called. It reads PDFs, Word, Excel, PowerPoint and text, plus text in images. A file named scan_0412.pdf that says "amount due" goes to Invoices.

undo.log

Every move can be reversed. Undo also removes folders the move created, if they're still empty.

never-overwrite.rule

Your files are moved, never deleted or replaced. If a name is taken, the new file becomes Report (2).pdf.

teach.rule

It learns from your corrections. Change a destination and Organizy offers to remember that kind of file next time.

rules.json

Rules you can read and edit. Match by file type, name, keywords or size. A live preview shows which files each rule catches.

local-ai.model

Optional AI that stays on your Mac. For files the rules aren't sure about, Organizy can ask Llama 3.2 running in Ollama. Nothing goes to the cloud.

folders/

where files go by default
~/Documents/Organizy/
├── Invoices & Receipts/   "amount due", "receipt", "factura"
├── Bank Statements/       "opening balance", "statement period"
├── Taxes/                 "W-2", "1099", "tax return"
├── Resumes & CVs/         "resume" in the name, "work experience"
├── Screenshots/           "Screenshot" in the name
├── Images/                jpg, png, heic, raw…
├── Videos/                mp4, mov, mkv…
├── Audio/                 mp3, wav, m4a…
├── Spreadsheets/          xlsx, csv, numbers…
├── Presentations/         pptx, key…
├── Documents/             everything else written
├── Archives/              zip, rar, 7z…
└── Installers/            dmg, pkg

Content rules come first, so a PDF receipt goes to Invoices before it can fall into Documents. Change any folder, add your own, or reorder them in Rules. Spanish keywords are included too.

install/

free · macOS 14 Sonoma or later
1 download

Get Organizy-x.y.z.zip from GitHub Releases, unzip it, and drag Organizy into Applications.

2 open

macOS blocks it the first time because Organizy is free and not notarized by Apple. Click Done, then go to System Settings → Privacy & Security and click Open Anyway. On macOS 14, right-click the app and choose Open instead. You only do this once.

3 verify

Optional. Each release lists a SHA-256 checksum. This command should print the same value: shasum -a 256 ~/Downloads/Organizy-*.zip

local-ai/ optional

1 ollama

Install Ollama, the free app that runs AI models on your Mac.

2 model

Download the model once (about 2 GB): ollama pull llama3.2

3 switch on

Turn on Local AI in Organizy. A green dot means it's ready. Organizy starts Ollama in the background when it needs it.
